# 英语听力优先：首批代码交付

2026-09-14。针对本人日常生活、同事沟通中听不懂的问题，在现有英语课程详情中加入听力练习。两小时为本人每日全部训练预算，包含现实交流；本次不伪造两小时课程内容或 60 天完整音频库。

## 已实现（本地待迁移）

- 进入已解锁的英语课，在阅读正文前看到听力面板。
- 两个手工样板：点咖啡、确认同事任务。每个有七句对话、逐句中文解释、四道理解题及新例子。
- 默认隐藏原文；播放完整对话、停止、展开原文、逐句重听。
- 完整播放结束才计次数；未完整播放或题目未答全时不接受检查。
- 每题标准答案和解析只保留在服务端材料模块；浏览器只收到展示所需的题目和选项。
- 练习按 READY → LISTEN → ANSWER → FEEDBACK → EXPLAIN → TRANSFER → SUMMARY 分步进行；原速完整播放是进入理解检查的服务端条件。
- `listening_sessions`、`listening_events`、`listening_attempts` 保存会话、帮助使用、不可覆盖的提交结果和既往曝光状态；支持跨设备恢复与重复请求去重。
- 新例子使用独立题组；用户看过原题答案后重新开始，只能作为复习记录，不会显示为首次独立答对。
- 最后可保存一条现实任务记录到既有笔记表；该记录不推进 `currentDay`，不加积分、不触发邀请或毕业。
- 切换场景、关闭页面或进入后台时停止当前朗读。
- 原有持久化英语对话增加同事确认任务场景，复用四语言场景标签。

## 当前限制

- 听力内容为中文讲解、英文设备合成语音；其他界面语言也明确显示该内容语言。尚无这两课的越南语、高棉语、泰语译稿。
- 使用设备 Speech Synthesis，尚非经过统一审核的录制音频；不能保证 Telegram 所有设备可播放。失败时提供文字学习，不标记听力成功。
- 浏览器播放完成不证明人认真听了；结果为自主练习记录，不发证、不加分、不替代原有课程提交。
- 浏览器只保留一份待恢复草稿提示；服务端记录是跨设备恢复与成绩的唯一可信来源。离线时尚未实现自动重放队列，失败操作会明确提示用户重试。
- 当前两个场景是样板补充，不替换历史课程版本或既有答题记录。
- Bot 原生语音收发、服务端语音识别与合成、Day 0 标准基线、完整 Day 1–7 课程、定时训练计划尚未交付。

## 验收

自动验证：生产构建、原有课程/对话回归、听力题目结构、答案不进入客户端材料、提交不接受客户端分数、严格请求字段、服务端 schema 覆盖检查。

本机未安装 PostgreSQL 客户端，且本地 `.env` 没有数据库连接配置；因此尚未执行这份新增迁移，也没有将代码部署到 VPS。发布前必须在隔离 PostgreSQL 运行 `npm run db:migrate:postgres`、`npm run db:check:postgres`，并实际验证 start/save/event/submit/finish 的重复请求、冲突和越权路径。

手机验收需覆盖：iOS/Android Telegram 完整播放、停止、后台切换、逐句朗读、答题、退出恢复、场景切换、存储受限提示、软键盘下笔记操作。自动测试不能代替真机声音与听感验收。

部署需带上既有英语对话改动与其数据库迁移，不能只复制页面文件。本次尚未发布到 VPS。
