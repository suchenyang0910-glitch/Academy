# Academy Knowledge Hub Source Register

> Purpose: record external learning materials that may inform Academy courses, without allowing them to automatically enter the active learning path.

## Source policy

- External sources are research material first, not course content.
- GitHub repositories must stay in `pending_review` until a human reviews relevance, license, maintenance status, difficulty, and fit with Academy's Evidence-first model.
- A source may support lesson rewrites, examples, quizzes, or recovery missions, but it must not change the MVP path, graduation criteria, or user progress by itself.
- Sources that are too broad or academic should be used as background references, not copied into 15–20 minute daily lessons.

## `microsoft-ai-for-beginners` review note

Use as an AI basics reference, not as Academy's main AI course.

Reasons:

- It is broad and long-form: suitable for background learning, not for the 15–20 minute daily supervised loop.
- It covers foundational AI concepts that can help clarify course explanations, but it is not directly project-delivery oriented.
- Academy's first AI template is `Build a Personal Knowledge Assistant`; the core path should prioritize model basics, prompt structure, context, RAG, tool usage, workflow, and evidence.

Allowed uses:

- strengthen AI Day 1–7 explanations;
- extract clearer beginner definitions after human review;
- generate recovery notes when users miss basic AI concepts;
- compare terminology against Microsoft learning material.

Not allowed in MVP:

- replacing the existing 21-day AI path;
- auto-generating lessons from the repository;
- changing quiz standards without Course Review Center evidence;
- marking any user progress based only on reading this source.
